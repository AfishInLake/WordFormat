# 小 BERT 训练数据补齐与重训报告

> 日期：2026-09-16
> 对象：uer/chinese_roberta_L-4_H-256 段落分类模型（22 类）
> 结论：**达到补齐目标**。长尾短板修复（20%→100%），留出集泛化 96.27%→98.11%，全量测试 1057 通过。

---

## 1. 背景与目标

此前版本模型在 6 篇留出论文上暴露长尾短板：`abstract_chinese_content` 仅 20%（真实训练样本 9 条），根因是**形态覆盖不足**而非数量不足。本次通过「合成数据补齐 + 重训 + 位置门控规则」修复。

## 2. 数据基线（补齐前）

| 维度 | 数据 |
|---|---|
| 论文数 / 段落数 | 34 篇 / 15493 段 |
| 类别数 | 22 类全覆盖，needs_review=0 |
| 长尾类（真实样本<120） | 13 类，最少 3 条（abstract_chinese_title）、9 条（中英摘要内容） |

### 2.1 泛化基线（留出法）

留出 6 篇未见论文（seed=42，教师强制 PREV 链）评测旧模型：

| 指标 | 数值 |
|---|---|
| 整体 acc | **96.27%**（1798 段） |
| abstract_chinese_content | **20.0%**（5/5 错 4，全被判 body_text） |
| 主力类别（正文/标题/目录/图注） | 96%+ |

问题样本形态："本文从制造工艺和经济效益两方面对 ECVT 变速器进行系统的评价"——**总结评价式摘要**，训练集 28 篇中没有此写法。

## 3. 合成数据方案

新增 [scripts/augment_synthetic.py](./scripts/augment_synthetic.py)：规则模板 + 词表随机组合，seed=20260916，产出 `training_data/_synthetic.json`（每条 comment="合成数据" 可追溯）。

| 项目 | 设计 |
|---|---|
| 总量 | **880 条**，覆盖 13 个长尾类 |
| 摘要内容（中/英） | 各 +120：主体强制"本设计/本文/本研究"句式；注入总结评价式模板（短板形态）；背景引入句（"随着…发展"）仅 15% 概率——与绪论首段词面同构，多给会把正文吸进摘要 |
| 标题类 | 摘要标题 20 条变体（"摘 要/中文摘要/内容摘要"等）、英文题名 60、文档标题 70 |
| 关键词/表注/附录 | 关键词各 110、表注 60（表X.Y 编号多样化）、附录标题 50 |

合成样本与真实文档同序列组织成 20 个伪文档，PREV 链自然。

## 4. 重训结果

| 阶段 | 数值 |
|---|---|
| 增强后训练集 | 13667 → 16061 → 16406 条（上采样每类≥120） |
| 训练 loss（3 epoch） | 3.75 → 1.77 → **0.96** |
| 模型产物 | fp32 33.6MB / **int8 8.6MB**（2 核 2G 上线版本） |

### 4.1 留出集对比（6 篇未见论文，1798 段）

| 指标 | 旧模型 | 新模型 |
|---|---|---|
| **整体 acc** | 96.27% | **98.11%**（+1.84pp）|
| abstract_chinese_content | 20.0% | **100.0%** |
| heading_level_1 | 97.6% | 100.0% |
| heading_level_2 | 88.9%* | 98.1% |
| heading_mulu | 96.8% | 100.0% |
| 全部 22 类 <90% 的类 | 3 个 | 0 个 |

*88.9% 为 28 篇子集训练时的数值，全量旧模型上为更高值；均不构成短板。

## 5. 端到端暴露的问题与修复

### 5.1 现象
合成摘要数据增强后，某真实文档 4 段绪论正文被吸入 `abstract_chinese_content`（例："紧跟人工智能和大数据技术的发展步伐，围绕智能电网…"）。摘要开场句与绪论首段在词面上本质同构，模型仅凭文本无法区分。

### 5.2 修复：位置门控规则
纯调合成数据已无边际收益，正确约束是**位置**。base.py 新增 `_gate_abstract_content`（后处理链第 4.5 步）：

> abstract_chinese_content / abstract_english_content 的相邻上一段必须是摘要标题或摘要内容，否则回退 body_text。

- 摘要内容从 6 段修正回真实 2 段，绪论段全部归位
- 新增 3 个单测，全量测试 **1057 通过**

## 6. 结论

1. **合成数据+门控组合达到目标**：留出集 98.11%，全部类别健康，最短板 20%→100%
2. **形态仍是长尾类的核心约束**：上采样只解决先验、合成解决形态；位置门控兜住与正文同构的边界
3. 后续若要继续提升：收集更多不同模板真实论文（尤其分多段摘要的工科设计说明书）扩充真实多样性
